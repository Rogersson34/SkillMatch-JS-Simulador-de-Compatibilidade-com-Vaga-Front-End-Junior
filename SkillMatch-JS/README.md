Aqui nós temos nosso projeto SkillMatch.JS, desenvolvido com HTML, CSS e JAVASCRIPT, onde nossos candidatos irão preencher os campos de vagas com nome, área de atuação, suas habilidades e o tempo de experiência.
Após o preenchimento iremos por buscar vagas, onde o nosso sistema irá mostrar  as vagas encontradas com maior compatibilidade e as com habilidades faltantes

Este é um mini-projeto desenvolvido para apresentação a fim de criar perfis de candidatos que sejam compatíveis com as vagas de desenvolvedores front-end júnior, de modo a comparar e analisar habilidades, nesse projeto teremos algumas ferramentas colacadas em prática, sendo elas;

-Arrays
-Arrow Functions
-Async/Await
-Bootstrap
-Callbacks/Closures
-Classes
-Construtores
-CSS
-DOM
-Eventos
-Fetch
-Funções
-GitHub
-Herança
-HTML Semântico
-JSON
-Laços de repetição
-Lógica de programação
-Métodos de array
-Objetos
-Operadores
-POO (Programação Orientada a Objetos)
-Promises
-Tipos de dados condicionais
-Trello
-Try/Catch
-Uso do this

O objetivo é automatizar e comparar as vagas correspondente a cada candidato;

- Habilidades que o candidato possui
-Habilidades que a vaga exige
-Quais habilidades faltam
-Qual é o percentual de compatibilidade com a vaga
-Qual candidato possui maior compatibilidade
-Qual recomendação de estudo deve ser dada ao candidato.
